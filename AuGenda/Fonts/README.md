# Accessibility Fonts

AuGenda currently ships only Apple system typography, which supports Dynamic
Type and avoids presenting an accessibility choice that silently falls back.

Custom fonts may be reintroduced only with:

1. binaries from an authoritative upstream release;
2. the complete applicable license;
3. file-signature and checksum validation in the release gate;
4. verified PostScript names and bundle registration;
5. Dynamic Type, VoiceOver, localization, and clean-install tests.
