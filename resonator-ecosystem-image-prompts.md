## Usage Notes for Image Generation

- **Recommended models:** Midjourney, DALL-E 3, Stable Diffusion XL, or Flux
- **Style modifier:** Append "photorealistic product photography, 8K, studio lighting, shallow depth of field, neutral gray background, no text, no logos" to any prompt
- **Color consistency:** All devices share matte black + amber LED + slate gray accent palette
- **Scale reference:** Include the Core in shots with attachments to show the magnetic dock relationship
- **Privacy indicator:** The red LED dot on recording devices is a key visual motif — always include when relevant
- **Ecosystem coherence:** If generating multiple products, reference the "matte black medical-grade aesthetic with amber indicators" to maintain visual consistency
